# 預金の予報（shisan-app）

楽天銀行の口座について、**今月末と来月末にいくら残りそうか**、**今いくら貯金に回せるか**を出すスマホ用のアプリ。`index.html` 1枚で動く。

## 画面（数字3つ）
| 表示 | 中身 |
|---|---|
| 今すぐ貯金に回せる | 今月いちばん少なくなる日の残高 − 残したい額（精算など「不確実」な入金は、入るまで数えない） |
| 今月末に残りそう | 月初の残高 ＋ 今月の入出金（予定・見込み・済をすべて） |
| 来月末に残りそう（ざっくり） | 今月末 ＋ 毎月の予定。カードは今月の利用額（メール）か、ひな型＋カードの支出メモ |

予定には「見込み → 確定 → 済」の印がつく。

## 入力するもの
| いつ | なに |
|---|---|
| 月初に1回 | 月初（1日）の口座残高 |
| 最初に1回 | ⚙設定：残したい額、毎月の予定（精算・家賃・給料・iDeCo・カード②・カード①） |
| 気づいたとき | ＋ボタン：支出メモ（カードで使った／口座から出る／口座に入る） |

数字はスマホの中（localStorage）だけに保存する。このリポジトリは公開なので、金額やURLはコードに書かない。⚙設定の「バックアップをコピー」で控えを取れる。

## 貯金の目安（Zaimの「貯金」を何円にするか）
| 状況 | 表示 |
|---|---|
| 今月が残したい額を超えている | 「支出を◯万に抑えた場合／Zaimの『貯金』（固定費）を◯円にできる／今の設定との差」＋スライダー（今月のカード利用の合計の上限） |
| 今月が残したい額に届かない | 「◯万にするために必要な額（今月 あと◯万、来月末 あと◯万 または『カード利用をあと◯万抑えると届く』）」＋「今月はZaimの貯金に入れない（0円）」。スライダーは出さない（今月の不足は、カードを抑えても変わらないため） |

- 貯金にできる額 ＝ 「今月の安全分」と「来月末（やや悪い側）の安全分」の少ないほう（1,000円未満は切り捨て）。今月の分だけ
- 理由は「計算の根拠」を開くと見える

## 預金の進捗（2つ目のタブ）
- いまの預金 ＝ 楽天（今日の時点の見込み）＋ SBI（⚙設定で手入力。変わったときだけ入れ直す）
- 月ごとの棒グラフ：棒＝実績（締めた月）、点線の棒＝見込み（今月末・来月末）、横線＝その月の目標、● ＝いま
- 月ごとの目標は ⚙設定に貼り付ける（1行に「2026-11 236」のように 年-月 と 万円）。公開リポジトリなので、金額はコードに書かず、スマホの中だけに保存する
- 月の締め：新しい月を開くと、前の月を見込みで仮に締める（推定）。その月の月初の残高を入れると、前の月の結果を実際の額（その残高＋SBI）で上書きする

## 今日の残高（設定）
⚙設定の「今日の残高」に口座の残高を入れると、その日までの入出金は残高に含まれているとみなし、そこから先だけを計算し直す（メールの取りこぼしでずれたとき用）。空にして保存すると月初の残高からの計算に戻る。

## 2027年2月からの切り替え（DC）
- iDeCoの引き落とし（26日・23,000円）は **2027年1月分まで** 予定に入っている。2月以降は自動で消える
- 給料は2027年2月から、DCが給料から先に引かれる分を見込んで **−3万円** にしてある（社会保険料が下がる分を差し引いた仮の値）。実際の手取りがわかったら ⚙設定の給料の金額を直す
- 楽天証券でiDeCoの積立を止める手続きが間に合わないと、2月26日に二重で引き落とされるので注意

## メールから自動で取り込む（任意）
`gas/Code.gs` を Google Apps Script に置くと、Gmail から次を読んでアプリに渡す（読むだけ）。

| メール | 使い道 |
|---|---|
| 楽天カード「お支払予定金額のご案内」 | カード①の引き落とし額と日 → 確定 |
| 楽天カード「速報版」 | 月ごとの利用額 → 翌月のカード①の見込み |
| 三井住友「ご利用のお知らせ」 | 月ごとの利用額 → 翌月のカード②の見込み |
| マネーフォワードME「入金／出金のお知らせ」（楽天銀行・1万円以上） | 精算・家賃・給料・カードの「済」と実際の金額 |

予定に当てはまらない入出金は「今月の流れ」の下に出るので、「追加」を押す。

### 見込みの出し方（過去の実績から）
| 項目 | 見込みの出し方 | 入金・請求が来たら |
|---|---|---|
| 精算 | 直近3回の入金の平均 | 実際の金額に自動で置き換え（済） |
| 給料 | いちばん新しい入金の額 | 実際の金額に自動で置き換え（済） |
| カード①② | 月の途中は「ここまでのペース」と「過去6か月の平均」を混ぜる（日がたつほどペース寄り） | 請求額が決まったら確定（①）、引き落としで済 |
| 来月末 | 今月末＋上の見込み。カードの「ペース」と「平均」の差から、ふれ幅も出す | – |

手で金額を直した行は、自動の見込みで上書きしない。

### GASを更新したとき
1. `gas/Code.gs` の中身を貼り替える
2. エディタで `setup` を1回実行する（毎日の自動更新が始まる）
3. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」（URLは変わらない）

### 設定の手順
1. https://script.google.com で新しいプロジェクトを作り、`gas/Code.gs` の中身を貼る
2. 「プロジェクトの設定」→「スクリプト プロパティ」に `TOKEN` を追加し、好きな合言葉を入れる
3. エディタで `test` を実行 → Gmail の許可を出す → ログに金額が出ればOK
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」→ URL をコピー
5. アプリの ⚙設定 に URL と合言葉を入れて「今すぐ取り込む」

URL と合言葉を知っている人は金額を見られるので、人に教えない。
